# Coryell County Taxpayer Watchdog
Three Governments. One Household Budget.

An independent initiative of The Coryell County Scoop.

## Canon policy
Official original documents are the authoritative evidence. Every published figure must identify document title, issuer, fiscal year, effective date, exact quoted entry, printed page (or explicitly unnumbered), PDF page, official URL, archived copy and SHA-256 when available. Preserve versions and corrections. Never silently replace conflicting records. Distinguish verified entries, calculations, projections and unresolved findings. Do not publish unverified figures as facts.

## Initial scope
Copperas Cove, Coryell County, CCISD. Mobile-first English/Spanish website, browser-only household calculator, document library, debt and spending dashboards. No personal financial data collection.

## Status
Initial evidence framework; calculations require source validation before public release.
